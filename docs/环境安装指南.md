# ShopCare 环境安装指南

本文档用于在 Windows、Linux 或 macOS 上完成服务启动、模型推理和训练环境准备。推荐使用 Python 3.11；BERT 训练建议使用 GPU，但服务和 RF/FastText 推理可以在 CPU 上运行。

## 1. 安装依赖

```bash
conda create -n shopcare python=3.11 -y
conda activate shopcare
pip install -r backend/requirements.txt
```

`backend/requirements.txt` 已包含 FastAPI、Uvicorn、Pydantic、PyMySQL、Redis、PyJWT，以及 RF/FastText 推理所需的 NumPy、scikit-learn、joblib、fasttext-wheel 和 jieba。

BERT 训练或推理需额外安装：

```bash
pip install torch transformers
```

数据分析脚本可选安装 `pandas`。Windows 安装 FastText 失败时优先使用 `fasttext-wheel`，代码中的导入名仍为 `fasttext`。

## 2. BERT 本地模型

项目不联网下载预训练模型。默认目录为 `04-bert/bert-base-chinese/`，至少应包含 `config.json`、`vocab.txt` 和 `pytorch_model.bin` 或 `model.safetensors`。

也可以通过环境变量指定其他本地模型目录：

```powershell
$env:BERT_MODEL_DIR = 'D:\models\bert-base-chinese'
```

未准备 BERT 模型时，服务仍可启动；`/models` 和 `/health` 会显示 BERT 未就绪，请求 BERT 时按配置降级到其他可用模型。

## 3. MySQL 与 Redis

两者都不是本地演示的硬依赖：

| 组件 | 正常用途 | 不可用时 |
|---|---|---|
| MySQL | 用户、工单、复核记录和审计日志持久化 | 降级为进程内 `MemoryStore`，重启后数据丢失 |
| Redis | 限流、分类缓存、令牌撤销记录 | 降级为进程内实现，多进程不共享 |

需要持久化时，复制环境变量模板并配置连接信息：

```powershell
Copy-Item backend/.env.example backend/.env
```

主要变量为 `DB_HOST`、`DB_PORT`、`DB_USER`、`DB_PASSWORD`、`DB_NAME`、`REDIS_HOST`、`REDIS_PORT`、`JWT_SECRET`、`ADMIN_PASSWORD`、`DEFAULT_MODEL`、`LABEL_THRESHOLD` 和 `GLOBAL_THRESHOLD`。部署时应替换默认认证配置。

手动建表：

```bash
mysql -u root -p < backend/schema.sql
```

## 4. 检查与启动

```bash
python tools/check_env.py
python tools/check_dataset.py
python tools/verify_all_phases.py --fast
python backend/main.py
```

访问地址：

- 页面：`http://127.0.0.1:8000/app`
- OpenAPI：`http://127.0.0.1:8000/docs`
- 健康检查：`http://127.0.0.1:8000/health`

## 5. 训练命令

```bash
python 02-rf/rf_train.py
python 03-fasttext/ft_train.py
python 04-bert/train_bert.py
```

训练脚本使用各自目录下的 `config.py`。由于三个目录存在同名配置文件，跨阶段脚本应使用独立进程；`tools/verify_all_phases.py` 和后端模型注册表已经处理了这一问题。

## 6. 常见问题

**分类结果总是拒识**：先查看输入是否属于演示数据分布，再检查 `LABEL_THRESHOLD` 和 `GLOBAL_THRESHOLD`。降低阈值会提高自动分流率，但可能增加错派风险。

**首次请求很慢**：模型采用懒加载，首次加载权重耗时属于预期行为，后续请求会复用进程内模型实例。

**为什么指标不能代表真实效果**：当前数据是经过泄漏隔离的合成语料，适合验证工程链路和模型相对差异；上线前必须用脱敏真实工单重新训练和评估。
